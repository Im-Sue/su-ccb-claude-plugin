# 节点手册通用约定

本文件收敛 7 个节点手册中纯通用的展示性样板。节点 `.node.md` 仍保留核心规则自包含：触发条件、步骤、完成条件、硬约束、sc 推荐、自检清单和恢复提示不得只放在本共享文件。

## 6 段手册骨架

每个节点手册采用 ADR-0030 的 6 段结构：

1. 什么时候进入这个模式。
2. 进入后大概怎么做。
3. 什么时候算这个模式完成。
4. 不能干什么。
5. 推荐的 sc 指令。
6. 好 / 中等 / 坏输出样例。

## 通用打回原因

所有节点默认适用：推荐 sc 不可用时，必须写明替代分析方式；缺少替代说明时应打回。

## 恢复纪律

恢复后重新读取当前节点的最新在手文件、EventJournal 和相关状态文件；如果恢复导致上下文或判断依据变化，重新完成该节点要求的最小协商和反思。
